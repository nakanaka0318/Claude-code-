# Claude-code-

## 知識ガチャ (`index.html`)

ガチャを回すと、いろいろな情報源からランダムな知識カードが出てくる 1 ファイルの Web アプリです。
`index.html` をブラウザで開くだけで動きます（ビルド不要）。

- 1回引く / 10連（10連は SR 以上を1枚保証）
- レア度: SSR 3% / SR 12% / R 30% / N 55%
- 引いたカードは「図鑑」としてブラウザ（localStorage）に保存

### 情報源

| 情報源 | 内容 |
| --- | --- |
| Wikipedia（日本語） | ランダムな記事の要約 |
| Wikipedia 今日は何の日 | 今日の日付の出来事（日本語がなければ英語） |
| REST Countries | ランダムな国の首都・人口・面積など |
| シカゴ美術館 API | パブリックドメインの美術作品と画像 |
| NASA APOD | 天文写真と解説（英語、DEMO_KEY のため回数制限あり） |
| Useless Facts | 英語の雑学 |
| Claude | claude.ai の Artifact として開いたときのみ |
| 内蔵雑学 | 通信できないときの予備（30件） |

取得に2回続けて失敗した情報源はそのセッション中は休ませ、どれも使えないときは内蔵雑学から出します。
