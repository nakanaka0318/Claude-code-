# 関ヶ原 3D

慶長5年9月15日（1600年10月21日）の関ヶ原の戦いを、ブラウザ上の3Dで再現したものです。
`index.html` をブラウザで開くだけで動きます（three.js を CDN から読み込むため、ネット接続が必要です）。

## できること

- 午前7時から午後4時半までの戦いを時間軸に沿って再生・早送り・巻き戻し
- 笹尾山・天満山・松尾山・南宮山・桃配山・伊吹山、中山道・北国街道・伊勢街道、藤古川を含む盆地の地形
- 東西36隊の布陣。兵・のぼり旗（家紋や旗印）・大将の馬印を表示
- 主な出来事を解説つきで再現
  - 朝霧と井伊直政の抜け駆けによる開戦
  - 笹尾山への総攻め、宇喜多隊と福島隊の攻防
  - 三成の狼煙、島津の不戦、南宮山の「宰相殿の空弁当」
  - 家康の陣場野への前進、問鉄砲
  - 小早川秀秋と脇坂ら四隊の寝返り、大谷吉継の自刃
  - 小西・宇喜多・石田隊の敗走、島津の退き口
- 部隊の名札をクリックすると、武将の解説と現在の兵力・状態を表示
- 硝煙・銃火・狼煙、時刻に合わせた霧の晴れ方と太陽の動き

## 操作

| 操作 | 内容 |
| --- | --- |
| ドラッグ | 視点の回転 |
| 右ドラッグ／二本指 | 視点の移動 |
| ホイール／ピンチ | 拡大・縮小 |
| スペース | 再生／一時停止 |
| ← → | 前／次の出来事へ |

## 注記

兵力と布陣位置は通説にもとづく概数です。地形は実際の地図を簡略化しており、縮尺は1単位＝約10m、兵の人形1体がおよそ75人を表します。
戦闘の推移は史実の流れに沿うよう台本化しており、損害の数値は演出上の目安です。
